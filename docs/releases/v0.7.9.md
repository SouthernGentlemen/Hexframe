# Hexframe v0.7.9

**Product:** Hexframe  
**Version:** v0.7.9  
**Release date:** 2026-09-02  
**Commit:** the commit this tag names — `git rev-list -n1 v0.7.9`

## Scope

Align Hexframe's public identity with the current WizardGang brand. Public headers now use the
offset acid and violet square mark and WIZARDGANG wordmark already published by the architecture
demo, while Hexframe remains the product descriptor. The root, Training, Codex, and sign-in
documents use the same mark as their browser icon.

This release also includes the completed retirement of the former ShadowMoney compatibility
surface from main after its explicitly authorized decommissioning.

## Included changes

- [HF-112] [OPS] Decommission ShadowMoney runtime
- [HF-113] [FEAT] Adopt current WizardGang brand mark
- [HF-114] [BUILD] Record and version the v0.7.9 brand-alignment release

## Brand boundary

- The WizardGang mark uses the exact `#d9ff43` acid square and `#a489ff` offset violet square from
  `demo.wizardgang.ai`.
- Public brand links pair WIZARDGANG with Hexframe as the secondary label.
- Product titles, game copy, navigation, interaction behavior, and supported-device policy are
  unchanged.
- Contract tests bind the public lockups and browser icons to the current mark.

## Known limitations

- Hexframe intentionally does not provide on-screen touch controls; mobile and tablet support is
  not planned.
- Desktop browsers in viewports at or below 960px receive the desktop-only notice and must widen
  the window to enter training.
