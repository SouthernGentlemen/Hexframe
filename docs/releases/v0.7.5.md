**Product:** Hexframe

## Scope

Harden Hexframe's complete HTTP boundary before accessibility work begins. Every public,
authenticated, asset, redirect, API, not-found, and error response now carries transport,
framing, capability, and content restrictions.

## Included changes

- [HF-104] [SEC] Harden every Worker response
- [HF-105] [BUILD] Record and version the v0.7.5 release

## Security boundary

- HSTS pins HTTPS for the host and its subdomains after the first secure visit.
- `X-Frame-Options: DENY` and CSP `frame-ancestors 'none'` prevent clickjacking.
- Permissions Policy disables camera, microphone, and geolocation access.
- The application CSP limits scripts and connections to Hexframe plus the configured
  Cloudflare Web Analytics hosts.
- The credential page keeps its stricter `default-src 'none'` policy.

## Known limitations

- The CSP permits inline styles because the current HUD, SVG renderer, and authored game
  views update style properties at runtime. Script execution remains restricted.
- Spatial fighting-game play remains primarily visual; supported menus and controls carry
  the scoped accessibility target.
