# Hexframe v0.7.8

**Product:** Hexframe  
**Version:** v0.7.8  
**Release date:** 2026-08-31  
**Commit:** the commit this tag names — `git rev-list -n1 v0.7.8`

## Scope

Correct the contrast of Hexframe's smallest muted interface labels. The public overview footer,
the desktop-only notice footer, and the in-game control legend now use a lighter muted tone that
clears the WCAG Level AA 4.5:1 text-contrast threshold on their dark surfaces.

## Included changes

- [HF-110] [FIX] Raise compact label contrast above WCAG AA
- [HF-111] [BUILD] Record and version the v0.7.8 contrast-correction release

## Accessibility boundary

- The 9px overview and unsupported-device footer labels use `#758089` on the darkest route
  surface, producing a contrast ratio above 4.5:1.
- The 9px in-game control legend uses `#758089` on `#0d1115`, producing a contrast ratio above
  4.5:1.
- Automated checks bind the audited color to each selector and calculate relative luminance using
  the WCAG contrast formula.
- Layout, label hierarchy, desktop-only support policy, and interaction behavior are unchanged.

## Known limitations

- Hexframe intentionally does not provide on-screen touch controls; mobile and tablet support is
  not planned.
- Desktop browsers in viewports at or below 960px receive the desktop-only notice and must widen
  the window to enter training.
